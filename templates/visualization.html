Visualize Your Excel Data

Upload an Excel file (.xlsx or .xls) to generate a default Bar Chart. You can then switch to Pie Chart or Infograph (A4 layout).

Important Limitations:
  • Only data from the first sheet is used.
  • The first column is treated as category labels.
  • The second column is expected to be numeric values.
  • Bar Chart displays all rows individually.
  • Pie Chart aggregates duplicate categories.
  • Infograph shows multiple sub-charts on an A4-like page (800×1100 px) in one figure.
  • Complex layouts, merged cells, or formulas might cause errors.
