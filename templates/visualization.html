Upload an Excel file (.xlsx or .xls) to generate a bar chart. Once displayed, use the toggle below to switch to a pie chart.

Important Limitations:
  • Only data from the first sheet is read.
  • The first column is expected to contain category labels.
  • The second column should contain numerical values.
  • Extra columns are ignored.
  • The bar chart displays individual rows; the pie chart aggregates duplicate categories.
  • Visualization may fail if the second column is not primarily numerical.
  • Complex layouts, merged cells, or formulas might cause errors.
